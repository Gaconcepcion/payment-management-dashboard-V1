# DAX measures

These are the DAX measures behind the Payment Management Tracking & Optimization Dashboard, exported for reference.

Table and column names have been genericized (e.g. `Posiciones de orden de compra` -> `Purchase Order Positions`,
`[Proveedor]` -> `[VendorID]`) so this folder does not expose the underlying production schema. Internal branding
strings embedded in the HTML component (`dssd-*` CSS classes) were replaced with `demo-*`. Business logic and
structure are otherwise unchanged.
